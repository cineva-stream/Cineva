# Security Policy

The Cineva maintainers take the security of our application and users seriously. We appreciate your efforts to responsibly disclose any vulnerabilities found in this software.

---

## Supported Versions

Only the latest release version receives active security updates and patches.

| Version | Supported          |
| :---:   | :---:              |
| v1.1.x  | Yes                |
| v1.0.x  | No                 |
| < v1.0  | No                 |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Cineva, please **DO NOT** open a public issue on GitHub. Publicly disclosing a vulnerability can put users at risk before a fix is ready.

Please follow these responsible disclosure steps:

1. **Email Details:** Send an email to **cineva.dev@gmail.com** with the subject line `[SECURITY] Cineva Vulnerability Report`.
2. **Include Necessary Context:**
   - A description of the issue and potential impact.
   - Exact steps or proof-of-concept (PoC) scripts to reproduce the behavior.
   - Affected devices, OS versions, and app builds.
3. **Response Timeline:**
   - We will acknowledge receipt of your report within **48 hours**.
   - We will investigate and provide an assessment or progress update within **7 business days**.
   - Once a fix is verified, a patch will be released promptly along with appropriate advisory credits to the reporter.

Thank you for helping keep Cineva and its users secure.
