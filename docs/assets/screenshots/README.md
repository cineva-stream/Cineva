# Cineva Application Screenshots

This directory stores visual assets and screenshots referenced in the main `README.md` and repository documentation.

### Standard File Naming:
- `02_home_discovery.png`: Home screen with featured movie/series shelves and trending carousels.
- `03_media_details.png`: Detailed media view showing metadata, cast, episodes, and stream options.
- `04_player_controls.png`: In-video player interface with custom controls and styled subtitles.
- `05_live_tv_landscape.png`: Live TV landscape mode showing the side channel drawer.
